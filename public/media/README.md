# EliasApp Media

Put child-safe, parent-reviewed media files here.

Suggested folders:

- `/public/media/images`
- `/public/media/images/screwdrivers`
- `/public/media/videos`
- `/public/media/sounds`

Example paths used by the app:

- `/media/images/garbage-front-loader.jpg`
- `/media/images/excavator.jpg`
- `/media/images/screwdrivers/phillips.jpg`
- `/media/images/screwdrivers/flathead.jpg`
- `/media/images/screwdrivers/stubby.jpg`
- `/media/images/screwdrivers/long.jpg`
- `/media/images/screwdrivers/toy-screwdriver.jpg`
- `/media/images/screwdrivers/electric-screwdriver.jpg`
- `/media/videos/my-safe-video.mp4`
- `/media/sounds/soft-horn.mp3`

If an image is missing, EliasApp shows a large friendly emoji placeholder instead.

Use parent-approved photos only. Avoid random copyrighted images, external hotlinks, and videos that have not been reviewed.
